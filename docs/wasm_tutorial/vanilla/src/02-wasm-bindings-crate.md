# The WASM bindings crate

The bindings crate stays thin. It initializes the parallel runtime and converts JavaScript numbers to the Rust types used by the computation crate:

```rust
#[wasm_bindgen]
pub fn calculate_fibonacci(workload: u32, num_threads: u32) -> u64 {
    computation::calculate_fibonacci(workload as usize, num_threads as usize)
}

#[wasm_bindgen]
pub fn mandelbrot_checksum(limit: u32, num_threads: u32) -> u32 {
    computation::mandelbrot_checksum(limit as usize, num_threads as usize) as u32
}
```

The `init_parallel_runtime` export is used by the worker setup generated by `orx-parallel-wasm`; on targets with atomics it calls `orx_parallel::init_thread_pool`. The app should not duplicate that initialization logic or reimplement the algorithms in JavaScript.
