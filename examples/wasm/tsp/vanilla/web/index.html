Parallel computation in WASM

A vanilla TSP demo with shared-memory wasm threads using orx-parallel.

Problem: TSP

Randomly create tours and locally optimize with two-opt Iterations times, and return the best tour.

Frontend

Vanilla Vite + TypeScript UI.

Sequential Code

(0..iterations)
    .map(|k| search_candidate(seed, locations))
    .min_by_key(|x| OrderedFloat::from(x.distance))

Parallel Code

(0..iterations)
    .into_par().chunk_size(chunk_size).num_threads(threads)
    .map(|k| search_candidate(seed, locations))
    .min_by_key(|x| OrderedFloat::from(x.distance))
